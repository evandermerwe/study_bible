# Contributing

Eric van der Merwe (`@evandermerwe`) maintains this repository. He decides what is merged.

## Pull requests

Every change to `main` is made through a pull request. Direct pushes to `main` are rejected. A pull request is merged only after an approving review from `@evandermerwe`. He is the only code owner, and his approval is required on every pull request.

Open an issue before starting a large change.
